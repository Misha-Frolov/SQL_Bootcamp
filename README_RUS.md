# SQL Bootcamp

Мои первые шаги в SQL.
Дата завершения проекта: 06.2024.

Проект состоит из 10 индивидуальных и двух командных заданий.
Каждый SQL-файл содержит задачу, которую необходимо было выполнить, за исключением day09 и team01, где имеются отдельные файлы README.

## Темы проекта:

- Day00 – как работает реляционная модель и как получать данные, используя базовые конструкции SQL
- Day01 – как работать с множествами данных и использовать простые JOIN
- Day02 – как объединять данные, используя различные типы JOIN
- Day03 – как изменять данные с помощью языка DML
- Day04 – как использовать виртуальные представления (views) и физические снимки данных (snapshots)
- Day05 – как и когда создавать индексы в базе данных
- Day06 – как добавлять новые бизнес-функции в модель данных
- Day07 – как применять OLAP-конструкции для получения “Value” из данных
- Day08 – как работают транзакции и уровни изоляции в базе данных
- Day09 – как создавать и использовать функциональные блоки в базе данных
- Team00 – реализация быстрого SQL-решения для задачи коммивояжёра (Traveling Salesman Problem)
- Team01 – что такое DWH и как создать первый ETL-процесс.
